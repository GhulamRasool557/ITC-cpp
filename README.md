# ITC C++ for Beginners

## Overview

* A **structured C++ practice repository** for university students taking **ITC (Introduction to Computing)**
* Starts from absolute zero and follows the **university ITC syllabus** step by step
* Inside each folder, tasks go from **easy to harder**. Open the folder's README to see the order.
* Part of a C++ series for university students: **ITC → PF → OOP → DSA**. Each course has its own repository, because each course allows different tools.

## Rules Followed in Every Code

* Only `#include <iostream>` with `using namespace std;`
* All code written inside `main()`
* No functions of our own, no built-in functions
* No `string` library and no C-string functions (`strlen`, `strcpy`, ...)
* No OOP or DSA concepts
* Simple and readable code

## Structure

| Folder | What's inside |
|---|---|
| **01- Hello World** | Your very first C++ program |
| **02- Integer Arrays** | Arrays of numbers: sum, search, sort, rotate, 2D arrays |
| **03- Character Arrays** | Text with character arrays: length, case, words, palindrome |
| **04- Patterns** | Star, number and alphabet patterns using loops |
| **05- ITC Projects** | Menu-driven projects using everything above |
| **06- Most Repeated ITC Codes** | The programs that come up again and again in ITC exams |
| **07- Midterm Questions** | Solved past midterm questions |
| **08- Final Term Questions** | Solved past final term questions |

Practise the folders in order. Try to write each code yourself first, and keep the midterm and final term folders for last.

## Target

* ITC students
* Absolute beginners in C++
